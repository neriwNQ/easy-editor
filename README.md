# easy-editor
easy photo editor
==============
**First you need to install the PyQt5 5.15.0 library using the pip install PyQt5 5.15.0 command.**
==============
**A simple photo editor in which you can: mirror the image, change the color of B/W, blur the image, change the sharpness.**
==============
**And also after exiting the application, the image will be automatically saved.**
